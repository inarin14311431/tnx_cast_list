このダッシュボードは GitHub Actions により自動生成されています(検証・本番いずれかの main への push、毎日 JST 早朝、または手動実行)。「反映済み」のうち番号明記以外は推定であり、確実な判定ではありません。

判定方法について
  • 番号明記: 本番PRの本文・タイトルに検証PR番号が明記されている場合(範囲指定・列挙を含む)。
  • ファイル一致(推定): 検証PRが変更したアプリ実行ファイル(js/, css-next/, *.html, config/, supabase/)の内容が、本番mainの現在の内容と一致する場合。
  • タイトル類似(推定): 上記で判定できない場合に、PRタイトルの類似度で本番側の対応PRを推定します。
  • アプリの実行に関わるファイルを変更していない検証PR(テスト・ドキュメントのみ等)は「対象外」として扱います。
