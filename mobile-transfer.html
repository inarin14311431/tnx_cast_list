CAST ID 読み込み中…

STEP 01 / FIRST TIME ONLY

転記BMをブックマークへ登録

初回だけ「転記BM」をコピーし、ブラウザのブックマークURLをコピーした javascript: から始まる文字列へ置き換えます。 既にスマホ用BMを登録済みの場合も、今回の正式版へ一度だけ更新してください。

スマホでの登録手順

iPhone / Safari：任意のページを一度ブックマークし、ブックマーク編集画面でURLをコピーした転記BMへ置き換えます。

Android / Chrome：任意のページをブックマークし、編集画面でURLを転記BMへ置き換えます。実行時はアドレスバーからブックマーク名を検索して開く方法が安定します。

STEP 02 / EVERY TRANSFER

このキャストの転記データをコピー

「転記TSV」を押すと、このキャストの転記データをクリップボードへコピーします。 キャストを更新した場合は、転記前にもう一度コピーしてください。

STEP 03 / CHARACTER SHEETS

倉庫を開いてBMを実行

「キャラクターシート倉庫を開く」を押すと、コピー済みTSVを検証・圧縮して倉庫へ移動します。 倉庫を開いた後、登録した「N◎VA転記」BMを実行してください。

キャラクターシート倉庫を開く VERIFY DATA / OPEN CHARACTER SHEETS

転記データはURLのフラグメント部分へ一時的に保持されます。フラグメントはサーバーへ送信されず、BMが読み取った直後にURLから消去します。

この方式で行わないこと

CAST ARCHIVEからキャラクターシート倉庫への直接POST、中間サーバーへの転記データ保存、編集パスワードの取得・保存は行いません。
