N◎VA CAST ARCHIVE // LEGACY IMPORT REFERENCE

旧方式（非常用）データ取込

このページは旧方式の記録・非常用案内です。
現在の通常の取込方法は、編集画面の「データ取込」からキャラクターシート倉庫URLを入力する方式です。ブックマークレットやJSONのコピー＆ペーストは通常は必要ありません。

現在の取込方法

1. N◎VA CAST ARCHIVEのキャスト編集画面を開く 2. 「データ取込 / IMPORT DATA」を押す 3. キャラクターシート倉庫の対象キャストURLを入力する 4. 「取込み」を押し、反映内容を確認する 5. 問題がなければ通常の保存ボタンで保存する

旧JSON／ブックマークレット方式について

過去には、キャラクターシート倉庫の画面でブックマークレットを実行し、取得したJSONをN◎VA CAST ARCHIVEへ貼り付ける方式を使用していました。現在は通常操作からは使用しません。

旧方式に関連するコードは既存データとの互換性確認や障害調査のために残していますが、新規利用向けの手順ではありません。通常のURL取込で問題が発生した場合にのみ、保守時の参照資料として扱います。

注意

取込結果が編集画面へ反映されても、その時点ではDBへ保存されていません。内容を確認し、保存ボタンを押して「保存済み」になったことを確認してください。
