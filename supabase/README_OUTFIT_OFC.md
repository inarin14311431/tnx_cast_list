# OFCアウトフィット項目対応

OFC固有項目をキャストのアウトフィットへ保存するため、Supabase SQL Editorで次を1回実行してください。

```text
supabase/22_outfit_ofc_details.sql
```

このSQLは次を追加します。

- `public.character_outfits.ofc_details`：OFC固有項目を保持するJSON列
- `public.save_character_bundle_with_ofc(...)`：従来のキャスト一括保存とOFC固有項目を同じトランザクションで保存するRPC

## 編集画面の表示ルール

共通：

- 隠匿値と隠匿ペナルティは、隠匿欄へ `隠匿値/ペナルティ` の形式でまとめる
- `ス`は`スロット`と表記する
- `部位／エリア`は`部位`と表記する
- `外界`列は表示しない

分類別：

- 武器：OFC大分類・小分類・メーカーを表示しない
- 防具：OFC大分類・小分類・メーカーを表示しない
- サイバーウェア：攻・受・射・スロット・防御S/P/I・部位・OFC大分類・小分類・メーカーを表示しない。全身義体は値が存在する項目だけを使用する
- トロン：IANUS表/深/無、CS値、OFC大分類・小分類、メーカー、参照P、隠匿ペナルティ、トロンのソ/サ/ハを列表示せず、値がある場合は解説欄へ記載する
- ヴィークル：OFC大分類・小分類・メーカー・隠匿ペナルティを表示しない
- 住居：OFC大分類・小分類・メーカー・隠匿ペナルティ・住宅の電/アを表示しない。住宅の登は`登場`と表記する
- その他：外界・攻・受・射・スロット・防御S/P/I・SF・部位・OFC大分類・小分類・メーカー・参照P・隠匿ペナルティ・制御値・電制・CS値を表示しない

非表示項目は既存データとの互換性とOFCマスタ再利用のため、`ofc_details`には保持します。

## OFC検索とTSV

- OFC検索から直接追加すると、必要項目を編集画面へ反映します。
- 隠匿値とペナルティは同じ隠匿欄へ反映します。
- トロンの非表示項目は解説欄へ整理します。
- 拡張TSVにはOFCデータを保持し、再取込時にも復元できます。
- 従来形式のOFC TSVも引き続き取り込めます。

Edge Functionの再デプロイやOFCマスタの再同期は不要です。SQL適用後、編集画面と閲覧画面を強制再読み込みしてください。
