# OFCアウトフィット全項目対応

OFCの不足項目をキャストのアウトフィットへ保存するため、Supabase SQL Editorで次を1回実行してください。

```text
supabase/22_outfit_ofc_details.sql
```

このSQLは次を追加します。

- `public.character_outfits.ofc_details`：OFC固有項目を保持するJSON列
- `public.save_character_bundle_with_ofc(...)`：従来のキャスト一括保存とOFC固有項目を同じトランザクションで保存するRPC

## 追加されるOFC項目

共通項目：

- OFC大分類
- OFC小分類
- メーカー
- 参照ページ
- 隠匿ペナルティ

分類別項目：

- 武器：受、ス、電制
- 防具：電制
- サイバーウェア：制御値、電制、IANUS部位（表・深・無）
- トロン：制御値、電制、トロン値（ソ・サ・ハ）
- ヴィークル：受、ス、制御値、電制、防御S/P/I、CS、乗員、SF
- 住居：電制、住宅値（登・電・ア）
- その他：制御値、電制、CS

既存のアウトフィットデータは削除・変更しません。従来、解説欄に入っていたメーカー、受、ス、制御値、電制、防御値、参照ページは、編集画面を開いた際に可能な範囲で追加欄へ読み替えます。

## OFC検索とTSV

- OFC検索から直接追加すると、OFCの全項目を編集画面へ反映します。
- OFC検索の「選択をTSVコピー」は、追加項目を含む拡張TSVを生成します。
- 拡張TSVをOFC TSV取込へ貼り付けると、追加項目も復元します。
- 従来形式のOFC TSVも引き続き取り込めます。

Edge Functionの再デプロイやOFCマスタの再同期は不要です。SQL適用後、編集画面と閲覧画面を強制再読み込みしてください。
